- Read [SECURITY.md](SECURITY.md) for any vulnerability or sensitive security report.

## Open A GitHub Issue When

- you found a reproducible bug in the runtime, CLI, HTTP API, MCP surface, or operator console
- documentation is materially incorrect or stale
- you have a concrete feature request tied to a product or runtime surface in this repository

When possible, include:

- exact commands or request payloads
- affected crate, path, or endpoint
- logs, traces, or screenshots
- what you expected and what happened instead

## Do Not Open A Public Issue For

- vulnerabilities or exploit details
- secrets, tokens, or private infrastructure details
- support requests that depend on private environment access you cannot share

Use [SECURITY.md](SECURITY.md) for those cases.
